# Re:Ultimate Maven artifacts

Pinned dependencies for the [Re:Ultimate](https://github.com/RE-Ultimate/Re-Ultimate) builds and launcher.
The original coordinates and bytes are retained for compatibility.

Use `https://raw.githubusercontent.com/RE-Ultimate/maven/main` as a Maven repository URL.
`artifacts.json` lists SHA-256 hashes. Existing versions must not be overwritten with different bytes.
